🧩 2-Look OLL + PLL 통합 치트시트

노란색 위 / 초록색 앞 / 흰색 아래 기준 · 큐브를 드래그해서 돌려보고 ▶로 공식을 재생
OLL 전체 OLL 1단계: 십자가 OLL 2단계: 코너 PLL 전체 PLL 1단계: 코너 PLL 2단계: 엣지
사용법
모든 케이스는 노란색 위 / 초록색 앞 / 흰색 아래 기준으로 시작함. 각 3D 큐브는 그 공식이 필요한 실제 색 상태에서 시작하고, 재생하면 공식 수행 과정을 그대로 볼 수 있음.
추천 순서
OLL은 십자가 → 코너 순서, PLL은 코너 → AUF → 엣지 순서로 보면 됨. 공식 박스를 누르면 복사됨.
