먼저 이것만 알고 보면 편함.
이 페이지는 모두 노란색 위 / 초록색 앞 / 흰색 아래 기준입니다. 아래 기호들은 공식 읽을 때 자주 나오는 것들만 추려서 넣었습니다.

공식 기호 설명

공식을 외울 때는 알파벳을 하나씩 외우기보다, 자주 나오는 덩어리로 익히는 게 훨씬 편합니다.

기본 자세
노란색 위(U) / 초록색 앞(F) / 흰색 아래(D) 기준으로 봅니다.
U
윗면을 90° 돌립니다.
D
아랫면을 90° 돌립니다.
R
오른쪽 면을 90° 돌립니다.
L
왼쪽 면을 90° 돌립니다.
F
앞면(초록색 쪽)을 90° 돌립니다.
B
뒷면(파란색 쪽)을 90° 돌립니다.
'
따옴표(')가 붙으면 반대 방향 90°입니다. 예: R'
2
숫자 2가 붙으면 180° 돌립니다. 예: U2
x
큐브 전체를 R과 같은 방향으로 돌립니다.
y
큐브 전체를 U와 같은 방향으로 돌립니다.
z
큐브 전체를 F와 같은 방향으로 돌립니다.
M
가운데 세로층을 돌립니다. M은 L 방향, M'은 R 방향입니다.
( )
공식을 외우기 쉽게 묶은 동작 덩어리입니다. 괄호 자체를 따로 돌리는 건 아닙니다.
( )3
괄호 안 동작을 3번 반복한다는 뜻입니다.
AUF
마지막에 U / U' / U2로 윗면만 살짝 맞추는 마무리 정렬입니다.

팁: 예를 들어 F (R U R' U') F'는 “F 하고, 오른손 트리거 한 번, F'”처럼 덩어리로 보면 더 잘 외워집니다.

목표: 노란 엣지 4개를 위로 올려 노란 십자가를 만듭니다.
